# Klyp P1 Post-Ready Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make saved clips post-ready inside Klyp with polished captions, quick transcript cleanup, speech polish, and suggested vertical framing.

**Architecture:** Extend the existing V3 editor and validated draft. Pure helpers decide edits and render parameters; the processing service renders them. UI presents clear previews, safe defaults, and undo. Auto-frame is on demand and bounded.

**Tech Stack:** Next.js 16, React 19, TypeScript, Supabase, FFmpeg, Node tests, browser interaction tests.

**Spec:** `docs/superpowers/specs/2026-10-24-klyp-p1-design.md`

## Global Constraints

- Keep saved clips, old drafts, ownership, Pro gates, and Free Original exports intact.
- Do not copy CapCut or OpusClip templates or assets.
- Bound FFmpeg arguments, AI frame count, response time, and user concurrency.
- Match preview/export geometry and document any audio preview approximation.
- Test old draft loading and real output before release.

## Review Focus

- Malformed draft settings cannot become CSS or FFmpeg injection.
- Automatic cleanup cannot delete words outside selected spans or create overlapping segments.
- Auto-frame failure leaves the user's manual crop untouched.
- Browser captions match burned captions on all aspect ratios.
- Audio changes do not alter raw export or clips without audio.
